# SuccessLabs Supply Chain Product Tour

Original, presenter-free learning demonstration inspired by SAP's public supply chain tour. Fictional OmniWorks data; no live enterprise integrations.

Serve this directory with any static HTTP server. No build dependencies. Edit `tour.js` for content, `app.js` for views and navigation, and `styles.css` for presentation.

See WALKTHROUGH.md for current source observations and design-qa.md for validation scope.
