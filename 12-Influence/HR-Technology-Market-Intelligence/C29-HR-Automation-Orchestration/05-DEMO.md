# 100-minute role-based demo

Personas: HR operations, hiring manager, IT service owner, finance controller, SAP architect and security reviewer.

| Minutes | Scenario | Proof |
|---|---|---|
| 0–10 | Current process and SAP baseline | Scope and baseline |
| 10–22 | Approved hire trigger | Event correlation |
| 22–34 | Country rules and decision table | Versioned rules |
| 34–46 | Parallel IT/finance/HR tasks | Process state |
| 46–58 | Human approval and escalation | Segregation |
| 58–70 | API action and justified RPA fallback | Supported integration |
| 70–80 | Duplicate, timeout and partial failure | Recovery |
| 80–88 | Unauthorized action and privacy | Negative tests |
| 88–96 | Monitoring, versioning and SLA | Operational evidence |
| 96–100 | TCO and decision | Commercial evidence |

Score orchestration 30%, integration 25%, governance 25%, experience 10%, TCO 10%. Challenge: IT ticket creation succeeds but response is lost; demonstrate reconciliation rather than duplicate ticket creation.
