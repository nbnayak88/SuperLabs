# C02 — 90-Minute Demonstration Script

**Personas:** employee, manager, HR tier-1 agent, payroll specialist, HR service owner, privacy officer, EC architect and procurement lead.

| Minute | Scene | Evidence |
|---|---|---|
| 0–8 | HR service vision and architecture | System boundaries and outcomes |
| 8–18 | Employee asks policy question via portal/Work Zone | Correct source-grounded answer |
| 18–28 | Employee raises payroll discrepancy case | Form, classification, case ID, acknowledgement |
| 28–38 | Agent receives and triages | Queue, employee context, assignment |
| 38–48 | Cross-team escalation and SLA | Clock, handoff, breach notification |
| 48–58 | Restricted employee relations case | Negative access test, audit |
| 58–68 | AI assistance | Summary, draft, human approval, safe refusal |
| 68–76 | Teams/email or other supported channel | Correlation, no duplicate case |
| 76–83 | Dashboard and knowledge improvement | FCR, backlog, SLA, CSAT |
| 83–90 | Implementation, migration and TCO | Written assumptions and exceptions |

## Objections to handle
- “Why not just use Work Zone?” Work Zone is the employee hub; evaluate ESM for the underlying case and agent operations.
- “Why not ServiceNow?” Compare HR data context, privacy, integration, workflow, cost and actual service outcomes with the same scenarios.
- “Can Joule autonomously resolve sensitive cases?” Require explicit human-in-the-loop controls and prove feature entitlement.
- “Can old Employee Central Service Center remain?” Confirm transition behavior and current SAP documentation before committing.

## Evaluation
Functional completion 30%; architecture 20%; privacy/security 20%; user experience 15%; evidence and implementation credibility 15%.
