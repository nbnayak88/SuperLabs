# C01 Presales Discovery — 30 Questions

**Workshop:** 120 minutes; CHRO/HR Ops, HRIS, EC architect, integration lead, IAM/security, payroll/time, analytics, regional HR and procurement.  
**Capture for each:** Answer | Country/entity | Priority | Current pain | Evidence | Owner | Open decision.

| ID | Theme | Question |
|---|---|---|
| D01 | Strategy | Which business outcomes justify Core HCM replacement or modernization? |
| D02 | Strategy | What is the global HR operating model and decision authority? |
| D03 | Scope | Which legal entities, countries, languages and employee populations are in scope? |
| D04 | Scope | How many active, future-dated, terminated and contingent records exist? |
| D05 | Scope | Are concurrent employment, global assignment and cross-border transfers required? |
| D06 | Data | What is the authoritative source for person, employment, job and organization? |
| D07 | Data | What historical depth and effective-dated records must migrate? |
| D08 | Data | Which custom fields, MDF objects and local fields are essential? |
| D09 | Data | What are current duplicate, invalid and orphan-record rates? |
| D10 | Organization | Position management or job management: which is required and why? |
| D11 | Organization | Which legal entity, department, cost center and location relationships are maintained? |
| D12 | Organization | How are reorganizations, mass transfers and matrix managers handled? |
| D13 | Process | Which hire, rehire, transfer, promotion, leave and termination variants exist? |
| D14 | Process | What are the workflow approvers, delegation rules and escalation SLAs? |
| D15 | Process | Which fields propagate/derive from associations and business rules? |
| D16 | Experience | Which employee/manager self-service journeys create most friction? |
| D17 | Experience | What mobile, accessibility and localization requirements are mandatory? |
| D18 | Security | Which roles may view/edit sensitive or country-specific fields? |
| D19 | Security | What SSO, identity provisioning, audit and SoD policies apply? |
| D20 | Privacy | What retention, residency, consent and cross-border transfer restrictions exist? |
| D21 | Integration | Which payroll, time, IAM, finance and third-party systems consume EC data? |
| D22 | Integration | What latency, sequencing, retry, replay and reconciliation are required? |
| D23 | Integration | What existing SAP Integration Suite, middleware and API assets can be reused? |
| D24 | Analytics | Which workforce KPIs and historical trend definitions are needed? |
| D25 | Operations | Who owns master-data correction, releases, regression and monitoring? |
| D26 | Migration | What cutover windows, parallel run and rollback tolerances exist? |
| D27 | AI | Which AI use cases are allowed and which require human approval? |
| D28 | Commercial | What are the licensing boundaries and 5-year TCO assumptions? |
| D29 | Delivery | What milestones, implementation partners and internal capacity are available? |
| D30 | Success | What objective acceptance thresholds will authorize go-live? |

## Required discovery artifacts

Current-state landscape; organization and legal-entity tree; sample effective-dated employee records (synthetic); integration inventory; RBP matrix; workflow map; migration sample; compliance register; KPI baseline; approved requirements backlog.

## Discovery outputs

Prioritized requirements, scope boundary, target architecture hypotheses, fit-gap log, critical assumptions, POC dataset and executive decision gates.
