# C06 Discovery — 35 Questions
**Participants:** TA lead, assessment psychologist, hiring manager, interviewer, HRIS/SAP architect, privacy/legal, security, integration lead, procurement.

| ID | Question |
|---|---|
| D01 | Which roles, geographies and hiring volumes are in scope? |
| D02 | What are the business outcomes and hiring-quality measures? |
| D03 | Which ATS and SAP Recruiting deployment path is authoritative? |
| D04 | Which roles require cognitive, personality, technical or situational tests? |
| D05 | What job-analysis evidence establishes assessment relevance? |
| D06 | Which validated assessment instruments are currently in use? |
| D07 | What reliability, validity and norming evidence is required? |
| D08 | Which jurisdictions regulate automated employment decisions? |
| D09 | Which candidate groups require accommodation or alternate formats? |
| D10 | Which interview stages and panel roles are used? |
| D11 | How are interview questions mapped to competencies? |
| D12 | How are interviewer rubrics calibrated across panels? |
| D13 | What candidate communication and consent is mandatory? |
| D14 | Are interview recordings permitted and how is opt-out handled? |
| D15 | Which languages and accessibility standards apply? |
| D16 | What are the acceptable candidate completion times? |
| D17 | What are the assessment retake and anti-cheating policies? |
| D18 | What are the data retention and deletion periods? |
| D19 | Which fields may be shared with specialist vendors? |
| D20 | How is candidate identity reconciled across systems? |
| D21 | Which scoring algorithms are explainable to reviewers? |
| D22 | What AI assistance is allowed before, during and after interviews? |
| D23 | What decisions must never be automated? |
| D24 | How are AI outputs reviewed, corrected and audited? |
| D25 | What fairness, adverse-impact and subgroup tests are mandated? |
| D26 | How are interviewer conflicts of interest managed? |
| D27 | Which assessment and calendar integrations are required? |
| D28 | How are failed API calls retried and reconciled? |
| D29 | What is the hiring-manager feedback turnaround target? |
| D30 | What dashboards and quality metrics are required? |
| D31 | How is candidate satisfaction measured? |
| D32 | What legacy records and consent evidence must migrate? |
| D33 | Which vendor contract, subprocessor and residency terms apply? |
| D34 | What implementation, licensing and AI budgets exist? |
| D35 | What POC evidence will authorize procurement? |

## Required outputs
Role-to-competency matrix; assessment validity and norming register; interview rubric; candidate consent matrix; data-flow diagram; accessibility/accommodation requirements; fairness risk register; SAP integration inventory; target KPIs; prioritized RFI.
