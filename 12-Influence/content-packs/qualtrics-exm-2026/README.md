## Business case

Evaluate a human-led enterprise EXM solution capable of lifecycle listening, continuous/pulse surveys, confidentiality-preserving analytics and closed-loop action planning. SAP SuccessFactors Employee Central is an employee master-data source, not a separate direct replacement for Qualtrics EmployeeXM.

**Ownership correction:** SAP sold its remaining Qualtrics stake in 2023. Qualtrics is not currently an SAP-owned company; integration with SAP SuccessFactors is a distinct consideration.

## Proposed solution value chain

Employee Central workforce and organizational hierarchy → approved, privacy-controlled data integration → employee lifecycle/pulse survey → response aggregation and text analytics → anonymized manager insights → action ownership → follow-up measurement.

## Critical evaluation principles

1. Distinguish Gartner research/Peer Insights coverage from an official ranked Gartner Top 10. The list below is a **curated shortlist, not an analyst ranking**.
2. Do not infer native SAP integrations, supported countries, AI capabilities, licensing or deployment requirements without vendor evidence.
3. Evaluate confidentiality thresholds, works council/legal restrictions, consent, DPA, data residency, and small-team reidentification risk.
4. Use the same scripted scenario, sample workforce, and rubric for all suppliers.
5. Require evidence (documentation and live demonstration) for each RFI claim.
