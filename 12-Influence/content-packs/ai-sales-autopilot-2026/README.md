# AI Sales Autopilot — Gojiberry-style prospecting skills pack (2026)

**Lab:** Presales Precision Lab (PSL) · `12-Influence`
**Reference product:** [Gojiberry](https://gojiberry.ai/) — capabilities taken from its public homepage only.

## What this pack contains

- [`SKILLS-PACK.md`](SKILLS-PACK.md) — the full pack:
  1. Gojiberry's 18 public capabilities (C1–C18)
  2. Coverage map: capabilities already served by installed `sales:*`, `marketing:*` and `brand-voice:*` skills versus gaps
  3. Twelve new skill specifications (S1–S12), each written as a SKILL.md body: ICP from website, buying-signal scout, lookalike audiences, visitor identification, contact-enrichment waterfall, intent lead scorer, multichannel sequence builder, prospect reply copilot, autonomy guardrails, conversion learning loop, benchmark report, and an end-to-end orchestrator
  4. Suggested build order, connectors, and compliance notes

## Activity contract (PSL)

| Field | Value |
|---|---|
| Challenge | Build an autonomous-but-supervised prospecting loop for an offer |
| Audience / level | Presales and sales practitioners, intermediate |
| Inputs | Offer URL, best-customer list, CRM or sheet of leads |
| Output artifact | `icp.json`, ranked lead list, reviewed outreach drafts, weekly learning memo |
| Default mode | Approve-first: drafts only, nothing sent automatically |

## Scope and status

Specifications only. No skill in this pack is claimed to be deployed, and Gojiberry's internal methods are not documented here. Automated LinkedIn messaging can breach LinkedIn's terms; outreach must respect India's DPDP Act, GDPR and CAN-SPAM. See section 6 of the pack.
