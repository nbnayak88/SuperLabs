# SuccessLabs Connected Finance Tour

Five finance chapters, 42 positions and three local learning experiments. Original fictional OmniVerse Energy data; no live enterprise integration.

Run `npm install`, `npm run dev`, and `npm run build`. Publish `dist/client/` with a relative base. Edit `src/tour.js` for the chapter model and sample views; `src/App.jsx` contains navigation, dialogs and experiments. See `public/WALKTHROUGH.md` and `design-qa.md` for source observations and verification.
