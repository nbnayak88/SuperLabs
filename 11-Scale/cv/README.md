# Online CVs (interactive)

Interactive, privacy-safe web versions of the CVs produced by the [`sla-cv-maker`](../templates/sla-cv-maker/SKILL.md) skill. Each page is generated from the same content as its Word (`.docx`) twin in a single run: filter by focus area, search, expand or collapse roles, switch light/dark theme, and save as PDF.

**Privacy defaults:** phone, email and named clients are omitted. The Word files are kept private and are not committed here.
