# Online CVs

Public, privacy-safe online versions of the CVs produced by the [`sla-cv-maker`](../templates/sla-cv-maker/SKILL.md) skill. Each page is generated from the same content as its Word (`.docx`) twin in a single run.

**Privacy defaults:** phone, email and named clients are omitted. The Word files are kept private and are not committed here.
